# Алгоритмы поиска в таблице при работе с данными из файла

## Задание 1. Преобразование текстового файла в двоичный

## Назначение
Программа считывает данные об автомобилях из текстового файла и формирует двоичный файл с записями фиксированной длины для организации прямого доступа к данным.

## Реализованные функции
* `bool textToBinary(const string& textPath, const string& binPath)` — считывает строки из текстового файла, заполняет структуру `carRecord` с очисткой памяти через `memset` и сохраняет её в двоичном режиме с помощью `write()`.
* `void printBinaryFile(const string& binPath)` — считывает файл блоками фиксированного размера через `read()` и выводит все записи на экран для проверки.

## Формат данных
* **Ключ:** номер автомобиля (`char[12]`)
* **Поля записи:** марка (`char[24]`), владелец (`char[32]`)
* **Входные данные:** `cars100.txt` (100 строк, поля разделены пробелами)
* **Выходные данные:** `cars100.bin` (двоичный файл фиксированных структур)
